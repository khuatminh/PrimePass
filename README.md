# PrimePass

PrimePass is a digital marketplace built with Java and Spring Boot.

## Technology

- Java 21
- Spring Boot 3.3
- Spring MVC, Spring Security, Spring Data JPA, and Bean Validation
- Thymeleaf and Bootstrap 5
- MySQL 8
- Maven and Lombok

## Tools

- Docker and Docker Compose
- Nginx and Let's Encrypt
- GitHub Actions for CI/CD
- VNPay sandbox payment gateway
